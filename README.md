The FacesApp app finds photos in the root folder and all subfolders, the path to which is specified as a parameter when launching FacesApp.

**How to build and use:**

1. git clone https://github.com/pavelpalityka/face_detector_project.git 1
2. cd face_detector_project
3. mkdir build 3
4. cd build 4
5. cmake .. 5
6. make 6
7. cd ../bin 7
8. ./facesapp <path_to_folder> 8

**Running tests:**
1. ./testd 1
